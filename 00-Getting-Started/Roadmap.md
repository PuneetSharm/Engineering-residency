# Engineering Residency Roadmap

> **"A roadmap does not tell you how to drive. It tells you where you are going and why the journey is organised in a particular order."**

---

# Introduction

This roadmap provides a high-level view of the Engineering Residency.

It is intentionally brief.

The detailed lessons, exercises, projects, experiments, documentation walkthroughs, and interview preparation are contained within the Engineering Handbook.

This roadmap answers one question:

**"Where are we going?"**

---

# The Final Goal

By the end of this residency, you should be capable of working confidently as a Frontend Engineer with strong engineering fundamentals while also being able to contribute as an AI Product Engineer.

This means you should be able to:

- Understand unfamiliar production codebases.
- Build production-quality frontend applications.
- Design maintainable frontend architectures.
- Understand backend fundamentals.
- Integrate AI into real products.
- Read official documentation efficiently.
- Explain engineering decisions confidently during interviews.
- Learn new technologies independently.

The journey is divided into multiple volumes.

Each volume builds on the previous one.

---

# Volume 1 — Foundations

Purpose:

Develop the engineering mindset before learning technologies.

Topics include:

- What software engineering is
- Thinking like an engineer
- Problem solving
- Engineering judgement
- Software development lifecycle
- Understanding products
- Internet fundamentals
- Browser fundamentals
- Development environment

Expected Outcome:

Understand how software is built before writing production code.

---

# Volume 2 — HTML

Purpose:

Understand how browsers interpret documents.

Topics include:

- HTML structure
- Semantic HTML
- Forms
- Tables
- Accessibility
- Browser behaviour
- HTML APIs

Expected Outcome:

Build accessible and meaningful web pages instead of simply arranging elements.

---

# Volume 3 — CSS

Purpose:

Learn how browsers render interfaces.

Topics include:

- CSS fundamentals
- Box model
- Layout systems
- Flexbox
- Grid
- Responsive Design
- SCSS
- Animations
- Performance
- Design systems

Expected Outcome:

Translate professional Figma designs into production-ready interfaces.

---

# Volume 4 — JavaScript

Purpose:

Master the language behind frontend development.

Topics include:

- Language fundamentals
- Scope
- Closures
- Objects
- Arrays
- Functions
- Event Loop
- Asynchronous programming
- DOM manipulation
- Browser APIs

Expected Outcome:

Develop strong JavaScript foundations instead of relying on frameworks.

---

# Volume 5 — TypeScript

Purpose:

Write scalable and maintainable applications.

Topics include:

- Types
- Interfaces
- Generics
- Utility Types
- Type Narrowing
- Project organisation

Expected Outcome:

Understand how TypeScript improves large applications.

---

# Volume 6 — React

Purpose:

Learn React from first principles.

Topics include:

- Rendering
- Hooks
- State management

- Performance

- Error Boundaries

---

# Volume 7 — Frontend Architecture

Purpose:

Topics include:

- Folder structure
- Feature-based architecture
- Shared components
- API layer
- Authentication
- Authorization
- State management
- Error handling
- Logging
- Security
- Performance optimisation
- Code reviews

Expected Outcome:

Think like a frontend engineer working on large production systems.

---

# Volume 8 — AI Product Engineering

Purpose:

Learn how AI is integrated into modern software products.

Topics include:

- AI fundamentals

# Volume 10 — Interview Preparation

Purpose:

Prepare for engineering interviews.

Topics include:

- JavaScript interviews
- React interviews
- Frontend architecture discussions
- Machine coding

# Continuous Learning Tracks

Some topics will run throughout the residency instead of belonging to one volume.

These include:

## Data Structures and Algorithms

Learn gradually through practical applications and increasing difficulty.

---

## Developer OS

Build one long-term engineering project from scratch.

---

## Portfolio

Develop a professional portfolio alongside technical growth.

---

## Office Observations

Learn from real production code and engineering decisions.

---

## AI Usage

Use AI as a mentor, reviewer, pair programmer, and learning assistant.

---

## Engineering Journal

Maintain daily reflections throughout the residency.

# Learning Philosophy

Every topic follows the same pattern.

Understand

↓

Study

↓

Experiment

↓

Build

↓

Reflect

↓

Revise

↓

Apply

This sequence will remain consistent throughout the residency.

---

# Measuring Success

Success is not measured by:

- chapters completed,
- hours studied,
- or technologies learned.

Instead, success is measured by your ability to:

- understand unfamiliar problems,
- reason through engineering decisions,
- explain concepts clearly,
- and build reliable software.
